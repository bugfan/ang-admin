🏗 系统架构

📄 文档处理：上传 → 文本提取 → 智能分块（800字符/块，100字符重叠）

🧮 向量索引：分块文本 → Embedding API → 向量存储（本地SQLite）

🔍 语义检索：用户问题 → Embedding → 余弦相似度匹配 → Top-K 结果

🤖 约束回答：检索结果 + 问题 → LLM（严格指令限制） → 精准答案

🛡 若检索结果相似度低于阈值，直接返回"无相关信息"，LLM 不参与，彻底杜绝幻觉。
